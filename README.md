# PN4AAR · 面向无人机自主对接的三维比例导引实验

用可旋转的三维场景，直观比较不同 PN 导引律在**同一相对运动状态**下给出的加速度指令。场景包含无人机、锥套目标、北东地坐标轴、视线和速度向量。

**[打开在线网页 →](https://pn4aar.luckygnome9.chatgpt.site)**

![PN4AAR 页面预览](preview.jpg)

## 可以做什么

- 切换 RTPN、TPN、PPN、IPN、APN、AIPN、BPN、BPPN、GTPN 和 ZEM-PN，共 10 个选项。
- 编辑三轴相对位置、相对速度、本机地速、目标加速度及偏置。
- 旋转、缩放三维场景，叠加基础导引律，比较指令方向和数值。
- 查看每个选项的具体公式、所需输入、适用边界和原始文献。
- 对所选 PN 做三维闭环轨迹积分，播放、暂停、拖动时间，查看最近间距与末相对速率。
- 使用“锥套在左，为什么向右加速？”预设，把位置、相对运动和加速度方向联系起来。

默认控制器完美跟随净加速度指令。轨迹采用理想质点模型，不实现位置 PID、姿态环或舵面控制。初始输入保持不变；改导引律或输入会清除旧轨迹，需要重新计算。

## 本地运行

安装 Python 3 后，在本项目文件夹打开终端，运行：

```sh
python -m http.server 8000
```

浏览器打开 [localhost:8000](http://localhost:8000)。结束时按 `Ctrl+C`。Windows 如果找不到 `python`，可用 `py -m http.server 8000`。

无需 npm、安装依赖或构建。Three.js 已放在 `vendor/`，浏览网页不依赖 CDN。请通过上述 HTTP 服务打开，直接双击 `index.html` 可能被浏览器的模块安全策略阻止。

## 检查公式与积分（可选）

安装 Node.js 18 或更新版本后，运行：

```sh
node test.mjs
```

成功会输出 `"passed":true`。测试使用固定随机种子，检查数值例、正交性、公式恒等关系、200 组状态的三维旋转协变性，以及零距离、零速度和负闭合速度等边界；另检查径向接近的解析到达时间、速度不变量、AIPN 恒加速度补偿、限幅及事件停止，共 22,285 项断言。它验证公式和理想质点积分，不验证真实飞行性能。

## 怎么看轨迹

1. 选择导引律和预设；需要时展开“编辑三轴输入”。这里输入的是初始状态。
2. 点击“计算轨迹”。浅色线是整个计算结果，实色线是已播放部分，蓝色为无人机、橙色为锥套。
3. 点击“播放”，或拖动时间轴；可切换透视、俯视、侧视。“看当前”放大当前相对几何，“居中”显示完整轨迹。
4. 展开“积分参数与模型”调整时长、最大步长、接近阈值和可选加速度限幅；限幅为 0 时关闭。

积分采用惯性 NED 坐标：

```text
pU(0) = [0,0,0]，pT(0) = r0，vT(0) = vU0 + vr0
pU_dot = vU，vU_dot = a_applied
pT_dot = vT，vT_dot = aT
r = pT - pU，vr = vT - vU
```

每个四阶 Runge–Kutta 子阶段都会重新计算 PN；目标 `aT` 在整个仿真中保持为给定的恒定 NED 加速度。所有选项的目标运动都使用该值，但只有 APN/AIPN 将它作为前馈输入。TPN 的 `Vc₀` 使用用户输入的固定值，整个积分中不更新；它不自动等于编辑后的初始闭合速度。

默认最大步长 0.02 s，时长 20 s，接近阈值 0.5 m。接近时进一步限制一步相对位移及加速度影响；检测阈值进入或距离由减转增后，二分定位步内事件，时间括区宽度不超过 1e-9 s。这是事件定位精度，不代表整段积分具有同等误差；可用较小步长复核结果。

停止原因是“进入接近阈值”“首次最近接近”或“达到设定时长”；另有非法状态和步数上限保护。最小间距指本次积分区间，首次最近接近不等于此后永远无法接近。初始状态已在阈值内时不继续积分。可选限幅作用于总指令的模长；此时右侧公式仍显示原始指令，轨迹面板和蓝色箭头显示执行指令。

**接近阈值是无人机质点参考点与锥套参考点的间距，不是探针尖端的接触判据。**机模按地速定向，未定义真实滚转；锥套也不包含软管动力学。这里没有末速度或末端方向控制，不把质点接近称为对接成功，也不把目标恒加速度情景称为真实锥套摆振。

## 目标在左，为什么还能向右加速？

PN 修正的是视线转动所反映的交会趋势，不是始终朝目标当前的位置加速。例如无人机朝北飞：

```text
r  = [20, -2, 0] m        锥套目前在左前方
vU = [10, 0, 0] m/s
vr = [-2, 1, 0] m/s       锥套相对向右运动
N  = 3
```

若双方保持原速度，10 s 后北向间距归零，锥套却已经从左侧 2 m 移到右侧 8 m。此时提前向右修正是合理的。RTPN 指令为 `[0.024703, 0.247035, 0] m/s²`；PPN 和 IPN 的东向分量也为正。

页面的“左右”按本机**水平地速方向**定义，右向单位向量为 `[-vU_E, vU_N, 0] / hypot(vU_N, vU_E)`。这不一定等于旋转视角后的屏幕左右，也不是考虑风偏后的机体左右。

## 公式约定

所有物理向量在右手北东地系 NED 中计算，单位为 m、s、rad。定义：

```text
r  = pT − pU                 相对位置：目标减本机
vr = vT − vU                 相对地速：目标减本机
R  = |r|，er = r / R         距离、视线单位向量
ω  = (r × vr) / R²           视线角速度向量
Vc = −er · vr                带符号闭合速度
Pr = I − er erᵀ              视线法平面投影
PU = I − ûU ûUᵀ              本机地速法平面投影
et = Pr vr / |Pr vr|         视线法平面内的相对速度方向
```

| 选项   | 本项目采用的加速度指令                                                |
| ------ | --------------------------------------------------------------------- |
| RTPN   | `N Vc (ω × er)`，使用实时闭合速度                                     |
| TPN    | `N Vc₀ (ω × er)`，使用固定初始闭合速度                                |
| PPN    | `N (ω × vU)`                                                          |
| IPN    | `N (vr × ω)`                                                          |
| APN    | `RTPN + (N/2) Pr aT`，经典横向近似的三维投影实现                      |
| AIPN   | `IPN + aT`，选用完整目标加速度补偿版本                                |
| BPN    | `RTPN + Pr b`，选用显式投影偏置示例                                   |
| BPPN   | `PPN + PU b`，选用速度法向偏置示例                                    |
| GTPN   | `N Vc norm(ω) (cosβ et + sinβ er)`，选用局部平面推广；`norm` 表示模长 |
| ZEM-PN | `(N/tgo²) Pr (r + vr tgo)`，`tgo = R/Vc > 0`                          |

PN 的命名并不完全统一；部分文献把这里的 RTPN 也称为 TPN。APN、BPN 等有多个版本，以上列出本项目实际实现的形式，不声称穷尽所有 PN。GTPN 在 `ω = 0` 时定义为零指令。ZEM-PN 在本页约定下与 RTPN 等价。

视线只有一个，各方法改变的是加速度指令的方向与尺度。PPN 的指令垂直于本机地速，IPN 的指令垂直于相对速度，TPN/RTPN 的指令垂直于视线。相同 N 下：

```text
aIPN − aRTPN = N |Pr vr|² er / R
```

因此 IPN 与 RTPN 的差异包含径向加速度，不能简单看成重命名参考方向，也不能仅据此判定哪一个性能更好。IPN 保持相对速率的结论要求目标匀速且加速度理想执行。

目标加速度 `aT` 是可编辑的已知示例输入，不表示视觉测量能可靠得到它。相对位置和速度必须来自同一参考点、时刻与坐标系。模型姿态、锥套朝向和尺寸仅用于示意；这里没有末速度、末角或对接成功保证。NED 到绘图坐标的转换为 `[E, −D, −N]`，保持右手性。
